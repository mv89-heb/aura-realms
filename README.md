# Aura Realms

Original 2D creature-exploration game built with Phaser 3 and Vite.

## Current vertical slice
- Verdant Meadow world
- Touch / mouse movement
- Original procedural player and wild creature visuals
- Encounter trigger
- Basic battle overlay
- XP, Aura and Crystals
- Local save
- Mobile portrait scaling

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.
